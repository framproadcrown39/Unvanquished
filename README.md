<a id="overview"></a>
Unvanquished is a **complete free download** for Windows, offering players a unique blend of first-person shooting and real-time strategy in a vibrant, futuristic world. This action-packed shooter allows players to engage in thrilling multiplayer battles where strategy and quick reflexes are essential for victory. As a fully open-source game, Unvanquished invites players to experience all features and updates without any limitations.

Launched in 2011, Unvanquished leverages a powerful graphical engine known as Daemon, which is an OpenWolf fork derived from the classic Quake 3 engine.
